# VEYRA: THE ONE-MAN ARMY FOR VIBE CODERS
> **Engineered by Muhammad Talha Farid**
> UNDERSTAND • ARCHITECT • BUILD • VERIFY • DEPLOY

When building software as a vibe coder, **Veyra transforms you into an entire engineering organization**:
- **Product Manager**: Socratic intent extraction, user journey mapping, and scope discipline.
- **Software Architect**: Relational schema modeling, API contract definition, official tech stack selection.
- **Senior Full-Stack Engineer**: Clean architecture, real state mutation, zero fake sleep timers (`Future.delayed` or `setTimeout`), hardware-backed security.
- **QA Automation Lead**: Multi-vector automated test harness, anti-mock sentinel, accessibility compliance.
- **DevOps Engineer**: Production Dockerfile, docker-compose, and GitHub Actions CI/CD.

---

## The 4 Universal Directives
1. **WHAT TO DO**: Extract underlying intent. Never implement raw prompt text blindly.
2. **WHY TO DO IT**: Every line of code, tool call, and component must serve clear user value.
3. **WHICH RESOURCE TO USE**: Official framework standards and native runtime primitives first. Zero unnecessary npm packages.
4. **WHEN TO STOP**: Stop immediately when requirements, edge cases, tests, and security are satisfied. Anti-loop circuit breaker prevents doom-loops.

---

## The 7 Vibe-Coding Superpowers
1. `veyra-brainstorming`: Socratic intent extraction and architecture blueprinting.
2. `veyra-writing-plans`: Atomic, bite-sized implementation plans with test criteria.
3. `veyra-executing-plans`: Phased progress execution with verification gates.
4. `veyra-systematic-debugging`: 4-layer root cause isolation (zero guesswork).
5. `veyra-tdd`: Test-driven verification and Directive 24 real-functionality sentinel.
6. `veyra-anti-generic-ui`: Bespoke design systems, fluid typography, no AI card clutter.
7. `veyra-deploy`: Multi-stage Docker, docker-compose, and CI/CD generation.
